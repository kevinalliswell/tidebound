# 潮生 · TIDEBOUND

可玩的 3D 海边生活机制原型。Three.js + Vite，中文界面，程序化场景和模型，无远程美术资源依赖。

## 运行

安装 Node.js 后，在此目录执行：

```sh
npm install
npm run dev
```

浏览器访问 http://127.0.0.1:5175 。构建：`npm run build`；规则测试：`npm test`。

## 操作

- WASD 移动 / 驾船 / 游泳；右键拖动转视角，滚轮缩放。
- 底部地点按钮自动步行前往，进入商店。
- 码头空格抛竿，咬钩后 7 秒内按空格提竿；默认辅助收线，可切换手动。E 使用钓法，T 选钓法，升级鱼竿可免费解锁。
- 船上 F 潜水；空格上浮、Ctrl 下潜；点击鱼捕猎，按住连发，Q 切换鱼叉与小刀。
- 船旁浮出水面按 E 登船；点击回港返回码头。
- I 背包、P 伙伴、Esc 暂停、H 隐藏界面。离开标签页自动暂停。

## 已实现的循环

- 钓鱼张力与收线进度，七种钓法，鱼骨原价五折。
- 船、3D 海底、躲避鱼、攻击生物、鱼叉射速和威力升级。
- 初始氧气 100%，基础每秒消耗 1%，超载倍增耗氧，升级增加续航。
- 缺氧船上复活，清空背包、保留仓库、存活鱼伙伴回缸、死去伙伴永久死亡。
- 两只开局鹦鹉，100 / 0 信任，吃鱼获得经验，满级 Lv.10 可击败巨物；自动捕鱼、致命攻击护主。
- 先买鱼缸才能养鱼伙伴，活鱼入缸、每日喂养、出战 / 召回；稀有活鱼可一键入缸并自动付费扩容。
- 17:00 红昏、19:00 入夜，顶部警告持续 3 秒；入夜 10 秒后出狼锁门，屋外梯子可用至第 30 秒，之后狼群追击。狼会游泳，不会上楼或攻击房屋，可驾船逃到 06:00 天亮。
- 卖鱼、入库、装备商店、寿司早中晚用餐、一鱼换三寿司、三元一份寿司。
- 开鱼铺从仓库零售、买房扩建，建筑高度随房子等级变化。
- 浏览器本地自动存档，玩法帮助中可手动保存和确认重开。

## 范围与限制

这是风格化 3D 机制原型，不是完成版写实商业游戏。当前有 13 类水生生物；没有实现全球全部鱼种、完整拟真水动力、完整武器动画、复杂巨物战、世界财富排行或多人联机。钓法以不同数值与控鱼效果体现，后续需要独立动作和更丰富的交互。稀有种按权重随机，无强制出场保底。

鱼叉和小刀击杀的鱼无法入缸；岸钓与伙伴活捉可保留活体，伙伴战斗击杀的鱼也无法入缸。进度仅保存在当前浏览器本地，清理网站数据会删除进度。水下查看面板仍消耗氧气，Esc 可以明确暂停。
